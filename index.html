// 03 — What I've Built

Projects & Work

Security Research · OWASP Juice Shop

Vulnerability Detection in OWASP Juice Shop

Complete security analysis of an intentionally vulnerable web application, combining manual penetration testing, log analysis, and machine learning for threat detection. Developed a Python-based IP reputation tool querying IPinfo.io and AbuseIPDB APIs to classify IPs as Safe, Suspicious, or Dangerous. Demonstrated critical cryptographic vulnerabilities including JWT brute-force, "none" algorithm exploit, and MD5 dictionary attacks.

Python JWT Security REST APIs Threat Intelligence Log Analysis Cryptography
01

Academic Project · ENSIAS 2025/2026

Badge-Based 2FA Access Control System

Designed and implemented a physical access control system using JavaCard smart card technology with two-factor authentication. Built a JavaCard applet integrating PIN verification, AES-128-CBC encryption of the RSA private key, and a Challenge-Response protocol for cryptographic authentication. Validated resistance against badge cloning, brute-force, and replay attacks through end-to-end testing.

JavaCard AES-128-CBC RSA Challenge-Response 2FA
02

First-Year Final Project · ENSIAS

Vulnerability Scanner Study with OpenVAS

Comparative study and hands-on implementation of open source vulnerability scanners (Nmap, OWASP ZAP, Nikto, OpenVAS) to strengthen information system security. Deployed OpenVAS on a Kali Linux virtual machine, configured the full GVM architecture, and simulated real-world attacks against a Metasploitable2 environment. Successfully detected a critical backdoor (vsFTPd 2.3.4) with detailed CVSS-based reporting.

OpenVAS Kali Linux Metasploitable2 CVSS Nmap Ethical Hacking
03

Internship · Architeo, Rabat — Sept–Dec 2024

Wi-Fi Auto-Connection & Network Access Control

Designed and deployed an automated Wi-Fi connection system with member self-registration for a coworking space. Built a custom captive portal with network access control based on pseudo-MAC address recognition. Implemented the backend in Node.js with SQLite for member and session management. Developed an admin dashboard for activation code management and network access monitoring.

Node.js SQLite Network Security Captive Portal MAC Authentication
